# HW 1: Bus Problem

## Problem Description
Creat a python code that calculates the total time a bus takes to complete its routes

## Instructions
Create a program called bus.py
○ The school bus starts its route at 9:35 am. It will complete its route in 47 minutes.
On that day, the bus will take 9 trips of the same duration.
○ In your program, you should have the following:
■ Have a starting hour with a variable titled start_hour
■ Have a starting minute with a variable named start_minute
■ Have the length of one full trip in minutes as trip_length
■ Find how many minutes in total the bus is taking for these trips
■ Add the minutes to the bus's start time
■ Must use floor division (//) and modulo (%) to find
● Hour when the bus is finished
● Minute when the bus is finished
■ Make a 24-hour to 12-hour conversion of the finish time
■ Print the finish hour as well as the minute.
○ The final time the bus should be finished is about 4:38 PM or 16:38
